# Ejercicios — Estructuras de Datos II
**Estudiante:** Ivan Lagos

Challenges del curso implementados en **Python**. Cada ejercicio está en **su propia rama**:

| Rama | Challenge | Tema |
|---|---|---|
| `challenge-03-listas` | 03 | Lista enlazada (reproductor de canciones) y lista doblemente enlazada (navegador atrás/adelante) |
| `challenge-04-pila` | 04 | Pila de libros (nombre, ISBN, autor, editorial) con formulario |
| `challenge-05-cola` | 05 | Cola de personas en un cajero ordenada por fecha de llegada aleatoria |
| `challenge-08-arbol-binario` | 08 | Árbol binario: inserción, InOrder/PreOrder/PostOrder, búsqueda y visualización |
| `challenge-09-arbol-nario` | 09 | Árbol N-ario de menús y submenús → menú lateral (DFS/BFS) |
| `challenge-10-grafo` | 10 | Grafo de personas y ciudades; personas que viven en una ciudad |
| `challenge-11-trie-heap` | 11 | Buscador por prefijo (Trie) + Top-K más populares (Heap) |

## Cómo ejecutar un ejercicio
```bash
git checkout challenge-04-pila
python challenge04_pila_libros.py
```
Requisitos: Python 3.10+ (no usa librerías externas).

> Las visualizaciones que en clase se planteaban con React (`react-d3-tree`, `react-d3-graph`) se hicieron en consola; los challenges 08 y 10 además generan un `.json` con el formato que usan esas librerías.
